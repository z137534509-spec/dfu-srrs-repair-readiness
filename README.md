# DFU stromal repair readiness analysis

This repository contains analysis code and derived result tables for the manuscript:

**Stromal repair readiness in diabetic foot ulcer healing: a multi-cohort single-cell and spatial transcriptomic study**

Authors: Zhong Shaowen and Sun Quan.

## Study Overview

The study asks whether diabetic foot ulcer (DFU) healing is associated with a fibroblast-centred stromal repair-readiness state. The analysis integrates public human wound datasets:

- GSE165816: DFU single-cell RNA-seq with 12-week healing outcome labels.
- GSE223964: chronic foot ulcer single-cell RNA-seq without healing outcome labels.
- GSE241132: human acute wound single-cell reference.
- GSE241124: human acute wound spatial transcriptomics.

The central output is the Stromal Repair Readiness Score (SRRS), a locked score linking fibroblast repair activation, stromal ligand expression, vascular/perivascular receiver context and day 7 acute wound fibroblast alignment.

## Repository Contents

- `scripts/`: R and Python scripts used for dataset processing, SRRS construction, robustness testing, external chronic wound projection, spatial projection, ligand-receptor analysis, perturbation-informed enrichment and figure/table generation.
- `results/srrs_framework/`: derived SRRS result tables used in the manuscript.
- `supplementary_tables/`: submission-ready supplementary tables and table index.
- `figures/`: submission-ready figure drafts.

Raw public datasets are not redistributed in this repository. They can be downloaded from GEO using the accession numbers listed above.

## Software

The analysis was performed on Windows using R and Python. Exact package versions may depend on the local single-cell objects available from the public datasets. Core dependencies include:

- R: Seurat, dplyr, ggplot2, Matrix, readr, tibble, tidyr.
- Python: pandas, numpy, scipy, statsmodels, matplotlib, seaborn, scanpy, anndata, openpyxl.

## Notes

GSE223964 is used for chronic wound fibroblast-state conservation, not independent DFU outcome validation. GSE241124 is used for acute wound spatial tissue context, not DFU spatial validation. The candidate ligand axes are hypothesis-generating and require prospective biopsy, protein-level and functional validation.
